01 / 基础

基础规范

少量、明确、有职责的基础变量。

颜色

按语义使用，而非挑选相近的灰色

常规内容使用前三档文字色；禁用色只用于不可用状态。状态同时通过文字或图标表达：错误一律使用三角警示图标，文案以“错误：”或具体的失败原因开头；警告（不可撤回、会对外产生影响，但还没有出错）使用菱形警示图标与左侧粗线，文案以“不可撤回：”等加粗短语开头。两者都用形状（双线、外框、左线、叉形标记）与字重区分，不依赖颜色。

页面接入约束

基础变量
颜色、字号、字重和间距只在 tokens.css 定义，JSON 同步导出。
公共组件
文字、内容块、操作、消息和输入区使用 g-* 类，变体在 components.css 维护。
页面样式
只负责布局与定位。若多个页面需要同一视觉调整，回到公共组件修改。
视觉验证
原稿内容样本与组合预览共用公共组件；在 320 / 390px 宽度检查长文、换行和操作状态。

应用组件接入

内容与操作
g-prose--list 排列无编号详情；g-prose-label / g-prose-copy 保持行内标签；g-btn--annotation 用于附件和辅助操作。
导航与旅程
g-nav / g-nav-item 使用图标、文字与选中圆点；g-timeline-item 使用细线和固定间距组织时间条目，data-status="running | done | failed" 对应圆环 / 实心点 / 叉形标记，并配 g-timeline-status 可见文字。
运行详情
g-tool 的 data-status="failed | interrupted" 时，标签内必须有图标和文字（#i-alert + “失败”，#i-stop + “已中断”），标签加外框（实线 / 虚线）；g-assistant-part 的 data-status="abandoned | interrupted" 时，内容前放 g-assistant-status（#i-stop + “已停止生成” / “已中断”）。
局部弹层
g-overlay + g-sheet--contained 复用弹层表面，容纳在应用视口中；g-list-action 复用文字操作和列表分隔。
状态反馈
g-toast 使用浅底与辅助字号，失败用 data-tone="error"（白底外框 + 警示图标 + role="alert"）；g-wave 静止时为禁用灰、聆听时为主要文字色，动效 700ms 并跟随减少动态效果设置，旁边必须有 role="status" 的可见文字。
错误与危险
错误提示用 g-hint--error（12 / 20，以“错误：”开头，#i-alert）；输入错误为双线下划线；危险操作用 g-btn--danger（细边框、600 字重、警示图标），并在独立弹层中最终确认。不可撤回等提醒用 g-hint--warning（#i-warning 菱形 + 左侧 2px 粗线 + 加粗开头），不要套用 g-hint--error。输入区发送失败用 data-state="failed"（底部双线，不加外框）并给输入框设 aria-invalid="true"。
0.4 / Light

0.4：新增独立的警告样式 g-hint--warning（不新增颜色），“不可撤回”改用警告；输入区失败态改为与输入错误一致的双线，不再与焦点框叠成双框，并补齐无“+”时的左内距；工具调用失败 / 中断与停止的回复增加外框、虚线、图标与文字。
0.3：补充错误、失败与危险状态（不新增颜色），标题与重点操作改用 600 字重，标签字号提升到 12px，输入区增加发送中 / 停止 / 失败状态，并修正悬停对比、标签页点击宽度与用户消息对齐。
